# Clay

A code editor for **Clay**, a simple language for making 2D games.
Each game has a `.claV` file (how things look) and a `.claS` file (how things behave).

## Install

Open this site in **Chrome** or **Edge** (Windows) or on a **Chromebook**, then:

- Click the install icon at the right end of the address bar, or
- Open the browser menu and choose **Install Clay** (Chrome: *Cast, save and share → Install page as app*).

Clay then opens in its own window, gets an icon in your Start menu / app launcher, and works offline.

## Your files

Projects save inside the app automatically. Use **Save to folder** in the Explorer to keep real
`.claV` / `.claS` files on your computer, and **Open folder** to load them again.
After installing, double-clicking a `.claV` or `.claS` file opens it in Clay.

## AI lines

Lines starting with `?` are plain English. Click **Translate** and Clay hands the request to
Claude on claude.ai: copy, paste into a chat, paste the reply back.
